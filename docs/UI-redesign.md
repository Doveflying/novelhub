# 书萤 · 界面重设计方案（原「轻库」）

> 版本 v1.0 ｜ 2026-10-24 ｜ 范围：网页端（桌面为主，兼容手机）
> 交付物：本方案文档、高保真原型 `design/prototype.html`、落地样式 `novelhub/webapp/static/ui.css`

---

## 1. 设计目标

书萤是一个「本地书库 + 在线源」的聚合阅读器，用户的核心诉求只有三件事：

1. **接着上次继续读**——打开就能回到那一章；
2. **找得到**——在小说 / 漫画 / 动漫之间快速切换、搜索、筛选；
3. **读得舒服**——长时间阅读不累，主题、字号、版心可调。

因此本次改版不追求"功能更多"，而是把已有的 12 个页面收进一套**稳定的外壳**，
让高频动作（继续阅读、翻章、换主题）永远在视线内，低频动作（抓取、导入、书源）
收进管理区，不再和内容争抢注意力。

**成功标准**

- 从打开首页到进入上次阅读章节：≤ 1 次点击
- 任意页面切换媒体类型：≤ 1 次点击
- 阅读页正文区域在 1440×900 下占比 ≥ 46%，且无干扰元素
- 所有可点击元素 ≥ 40×40，键盘可完整操作
- 四套主题下正文对比度均 ≥ 7:1

## 2. 现状审计

| # | 问题 | 影响 | 处理 |
|---|---|---|---|
| 1 | 顶栏 8 个文字入口 + 2 个无标签图标平铺 | 主次不分，管理功能与内容入口混在一起 | 改为左侧导航：媒体 / 我的 / 管理 三组 |
| 2 | 首页是均质封面墙，没有「继续阅读」区 | 最高频动作被埋进每张卡片 | 首页顶部新增继续阅读区 |
| 3 | 每张卡片都放「目录 / EPUB / 删除」 | 视觉噪音大，误删风险 | 卡片只留「继续阅读」，其余进详情页与 `···` 菜单 |
| 4 | 删除按钮紧邻阅读按钮 | 误操作成本高 | 移出卡片；删除改为二次确认弹窗 |
| 5 | 阅读页无进度百分比、目录入口只有图标 | 长篇阅读缺少位置感 | 顶部进度条 + 百分比，工具栏常驻可呼出 |
| 6 | 主题切换是「◐」循环按钮 | 不知道当前主题、要循环四次 | 四主题可视化选择器，带预览色块 |
| 7 | 字号/行距/版心是三个滑杆，无预设 | 调参成本高，不知道调到哪合适 | 预设（小/中/大/特大）+ 细调 |
| 8 | 状态标签（在线读/部分/已下载）颜色语义弱 | 无法一眼判断书籍状态 | 统一状态点 + 文案，绿=完整、橙=部分、蓝=在线 |
| 9 | 空状态、错误、加载样式各自为政 | 体验不连贯 | 统一空状态 / 骨架 / Toast 规范 |
| 10 | 移动端只是顶栏换行 | 手机上导航拥挤、点击目标小 | 底部标签栏 + 抽屉式「更多」 |

## 3. 用户与任务

**主要用户：重度轻小说读者（桌面）**
- 场景：晚上在电脑前连续读 1–3 小时，书库里 10–50 本，部分在线读、部分已下载。
- 任务：接着读 → 翻章 → 偶尔查目录 → 调暗主题。
- 痛点：找不到上次读到哪、翻章要滚动到底、夜间主题切换麻烦。

**次要用户：仓鼠型收藏者**
- 场景：批量抓取/导入，整理书库，导出 EPUB。
- 任务：看抓取进度、补抓缺章、确认哪些书已完整。
- 痛点：状态不直观、管理入口和阅读入口混在一起。

**第三用户：手机端碎片阅读**
- 场景：通勤时打开同一局域网地址读一两章。
- 任务：单手继续阅读、翻章。
- 痛点：顶栏太挤、按钮太小。

## 4. 信息架构

```
书萤
├─ 媒体
│  ├─ 书架（小说）        /
│  ├─ 漫画                /comics
│  └─ 动漫                /animes
├─ 我的
│  ├─ 历史                /history
│  └─ 发现                /discover
└─ 管理
   ├─ 抓取                /crawl
   ├─ 导入                /import
   └─ 书源                /sources
```

**导航模型**

- 桌面（≥ 1080px）：左侧固定导航 244px，可折叠为 76px 图标栏；顶部为页内工具栏（搜索 / 添加 / 主题）。
- 平板（720–1079px）：左侧导航折叠为图标栏，内容区自适应。
- 手机（< 720px）：隐藏侧栏，底部 5 项标签栏（书架 / 漫画 / 动漫 / 历史 / 更多），
  「更多」为底部抽屉，收纳发现、抓取、导入、书源、主题。
- 阅读页：进入沉浸模式，隐藏全局导航，仅保留悬浮工具栏与底部翻章条。

**页面层级**

| 层级 | 页面 | 返回方式 |
|---|---|---|
| L1 | 书架 / 漫画 / 动漫 / 历史 / 发现 / 管理 | 侧栏 |
| L2 | 书籍详情 / 漫画详情 / 番剧详情 | 面包屑「← 书架」 |
| L3 | 阅读器 / 漫画阅读 / 播放 | 顶部返回 + Esc |

## 5. 设计概念：纸上书房

关键词：**纸感、留白、朱砂、克制**。

不是"后台管理系统"，而是一间安静的书房：米白纸面、墨色文字、一点朱砂做强调，
封面是唯一的高饱和色块。信息靠**字重、留白、细分隔线**分层，而不是靠阴影和色块堆叠。

**五条原则**

1. **内容优先**：界面元素退后，封面与正文是主角；装饰只用在标题与分隔。
2. **一个页面一个主动作**：书架=继续阅读，详情=继续阅读，阅读=翻章。
3. **状态可读**：颜色 + 文案 + 形状三重编码，不只靠颜色。
4. **手感**：所有可点元素有 hover / active / focus 三态，动效 120–220ms。
5. **不打扰**：低频操作收进菜单；阅读时自动隐藏 chrome。

## 6. 设计语言

### 6.1 色彩

四套主题共用同一组语义变量，只换值。默认「纸」。

| Token | 纸（默认） | 黄（护眼） | 绿（护眼） | 夜 |
|---|---|---|---|---|
| `--bg` | `#F6F2E9` | `#F2E7D3` | `#E9EFE3` | `#131519` |
| `--surface` | `#FFFDF8` | `#FAF0DE` | `#F4F9EF` | `#1C2027` |
| `--surface-2` | `#F1EBDD` | `#EADCC3` | `#DFE8D7` | `#232830` |
| `--ink` | `#1F1C18` | `#2A2118` | `#202A1D` | `#E9E4D9` |
| `--ink-2` | `#4A443C` | `#4C4030` | `#3C4636` | `#C3BCAF` |
| `--muted` | `#7A7267` | `#7C6A52` | `#68725F` | `#948D82` |
| `--line` | `#E4DCCC` | `#DDCDB2` | `#D2DDC9` | `#2B303A` |
| `--accent` | `#B0442D` | `#8F4B26` | `#4C6B3F` | `#D97757` |
| `--accent-soft` | `#F4E3DA` | `#EFDCC5` | `#DDE8D3` | `#2E211D` |

语义色：`--jade #3C6E57`（完整/成功）、`--amber #9A7638`（部分/警告）、`--blue #3A6480`（在线/信息）、`--danger #A83A2C`。
夜间模式整体提亮 12%，保证对比度。

**使用比例**：背景 60%、表面 30%、墨色 8%、强调色 ≤ 2%。一屏最多出现一处朱砂实心块（主按钮）。

### 6.2 字体

- 衬线（标题 / 书名 / 正文）：`Source Han Serif SC → Noto Serif CJK SC → Songti SC → STSong → SimSun`
- 无衬线（界面 / 元信息）：`PingFang SC → HarmonyOS Sans SC → Microsoft YaHei → system-ui`
- 等宽（数字 / 快捷键）：`ui-monospace → Consolas`

| 角色 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| Display | 32 / 1.3 | 600 | 详情页书名 |
| H1 | 26 / 1.35 | 600 | 页面标题 |
| H2 | 20 / 1.4 | 600 | 区块标题 |
| H3 | 16 / 1.5 | 600 | 卡片标题 |
| Body | 14 / 1.65 | 400 | 界面正文 |
| Meta | 12.5 / 1.5 | 400 | 作者、章节数、时间 |
| Caption | 11 / 1.4 | 500 | 标签、眉题（大写 + 字距 0.08em） |
| Reading | 19 / 1.95 | 400 | 正文，可调 16–30 |

正文首行缩进 2em，`text-align: justify`，中西文混排用 `text-spacing-trim`（支持的浏览器）。

### 6.3 间距与栅格

4px 基准：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56 / 72`。
桌面内容最大宽 1200，左右留白 32；阅读版心 38em（约 720px），可调 32–48em。
书架网格：`repeat(auto-fill, minmax(178px, 1fr))`，间距 24×32。

### 6.4 圆角 / 阴影 / 描边

- 圆角：控件 10、卡片 14、面板 20、胶囊 999。
- 阴影：`--shadow-sm 0 1px 2px rgba(31,28,24,.05)`；`--shadow-md 0 10px 30px -14px rgba(31,28,24,.25)`；`--shadow-lg 0 30px 70px -30px rgba(31,28,24,.35)`。
- 描边：1px `--line`；hover 时边框过渡到 `--line-strong`，不靠阴影表达可点。

### 6.5 图标

线性图标，1.6px 描边，20×20，圆角端点；当前选中态可用实心小圆点标识。
统一使用内联 SVG sprite，避免图标字体与额外请求。

### 6.6 动效

- 进入：`opacity 0→1 + translateY(6px)`，180ms `cubic-bezier(.2,.7,.3,1)`
- hover：背景/边框 140ms；卡片上浮 2px + 阴影 180ms
- 抽屉：translateX 220ms；底部面板 translateY 240ms
- 尊重 `prefers-reduced-motion`，关闭位移与骨架动画。

## 7. 组件规范

### 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| Primary | 墨色底 / 纸色字（夜间反相） | 页面唯一主动作 |
| Accent | 朱砂底 / 白字 | 继续阅读（仅首页与详情） |
| Secondary | 透明底 + 1px 边框 | 次级动作 |
| Ghost | 无边框，hover 出底色 | 工具条、图标按钮 |
| Danger | 透明底 + 危险色字 | 删除（仅菜单/详情） |

尺寸：`sm 30px / md 38px / lg 44px`；图标按钮 40×40；手机端最小 44×44。

### 书籍卡片

- 封面 3:4，圆角 12，`object-fit: cover`，加载失败显示书名首两字（衬线、朱砂淡底）。
- hover：上浮 2px、封面轻微放大 1.02、底部浮出「继续阅读」胶囊。
- 封面右下角状态点：绿=已下载、橙=部分、蓝=在线。
- 卡下信息：书名（衬线 15，两行截断）→ 作者 · 分类（12.5 灰）→ 进度条 + 百分比。
- `···` 菜单：目录 / 导出 EPUB / 换源 / 删除。

### 继续阅读卡（首页）

- 240×148 起，横向滚动；左侧 72×96 封面，右侧眉题「继续阅读」、书名、读到章节、进度条与百分比、主按钮。
- 最多展示 3 张，按最近阅读排序；无进度时整块隐藏，改为「开始第一本」引导。

### 状态标签

`已下载`（jade）、`部分`（amber）、`在线读`（blue）、`未抓取`（灰）。
胶囊形，11px，前置 5px 圆点；不使用纯色填充，避免与主按钮抢注意力。

### 输入 / 搜索

高 38，圆角 10，内嵌搜索图标；聚焦时边框变 accent + 2px 外发光（`box-shadow: 0 0 0 3px accent-soft`）。
全局搜索支持 `⌘K / Ctrl+K` 聚焦，`/` 快速聚焦，`Esc` 清空。

### 抽屉 / 面板 / 弹窗

- 左抽屉：目录（宽 360，含搜索与分卷折叠）。
- 右抽屉：阅读设置（宽 320）。
- 底部面板（手机）：主题 / 更多。
- 弹窗：仅用于破坏性操作，最大宽 420，标题 + 说明 + 取消/确认。

### 空状态

虚线边框 + 衬线大标题 + 一句解释 + 一个主按钮。文案不卖萌，给下一步。

### 加载

骨架屏使用 3 段渐变 shimmer；超过 400ms 才显示，避免闪烁。
长任务（抓取）用进度条 + 实时日志，不阻塞页面。

### Toast

底部居中，深色底、纸色字，2.8s 自动消失；同屏最多 1 条。

## 8. 关键页面

### 8.1 书架（首页）

1. 页头：眉题 `LIBRARY`、标题「书架」、右侧统计（12 本 · 2,726 章 · 38.4 万字）。
2. 继续阅读区：横向卡片，最多 3 张。
3. 工具条：分类页签（全部 / 在读 / 已下载 / 在线）、排序（最近更新 / 书名 / 进度）、视图切换（网格 / 列表）。
4. 书架网格；卡片主动作「继续阅读」，`···` 收纳其余。
5. 空状态：引导抓取或导入，附支持站点说明。

### 8.2 书籍详情

- 顶部返回 + 面包屑。
- 首屏：封面 200px、书名、作者/文库/状态、字数与章节统计、简介（默认 4 行，可展开）、
  主动作「继续阅读」+ 次动作「目录」「更多」。
- 阅读进度卡：读到第几卷第几章、百分比、继续按钮。
- 目录：按卷分组，粘性卷标题，双列章节；当前章朱砂高亮；未抓取章灰色 + 「未抓取」标签。
- 底部：补抓缺章、导出 EPUB/TXT/MD、换源（收进「更多」菜单）。

### 8.3 阅读器

- 顶部：返回、书名 / 章节、进度百分比、目录、Aa、书签。
- 正文：眉题（卷名）、章节标题（衬线 30）、字数与时间、细分隔线、正文 19/1.95、首行缩进 2em。
- 底部悬浮条：上一章 / 进度滑杆 / 下一章（已缓存时显示「已缓存」）。
- 工具栏滚动向下自动隐藏，向上或移到顶部出现；`T` 目录、`S` 设置、`←/→` 翻章、`Esc` 关闭。
- 设置：主题 4 选 1（带预览）、字号（16–30，步进 1，显示 px）、行距（1.6–2.4）、版心（32–48em）、
  字体（宋 / 黑）、恢复默认。

### 8.4 历史

- 顶部：标题 + 总数 + 清空（二次确认）。
- 筛选：全部 / 小说 / 漫画 / 动漫。
- 按「今天 / 昨天 / 更早」分组；行内：封面、书名、读到章节、来源、时间、继续按钮、移除。
- 空状态说明「历史只记读过什么，不影响书架进度」。

### 8.5 搜索

- 大搜索框（自动聚焦）+ 最近搜索 / 热门标签。
- 两个页签：本地书库（书名/章节/正文）、在线书源（聚合搜索）。
- 结果行：封面、书名、作者、来源、命中片段（高亮关键词）、动作「继续读 / 加入书架 / 抓取」。
- 无结果：给出「到在线书源搜索」的跳转，而不是死胡同。

### 8.6 书源管理

- 概览卡：可用 / 异常 / 停用 数量，最近检测时间。
- 表格：源名、类型、状态、延迟、最近检测、开关、重测。
- 异常行浅红底 + 「建议关掉」提示；批量检测按钮在右上。

## 9. 交互与快捷键

| 键 | 行为 |
|---|---|
| `⌘K` / `Ctrl+K` | 聚焦全局搜索 |
| `/` | 聚焦搜索（非输入态） |
| `←` / `→` | 阅读页上一章 / 下一章 |
| `Space` | 阅读页向下翻页 |
| `T` | 打开目录 |
| `S` | 打开阅读设置 |
| `Esc` | 关闭抽屉 / 面板 / 弹窗 |
| `G` 然后 `S` | 回书架（可选，v1.1） |

其他规则：

- 阅读进度 1.2s 防抖写入；离开页面前 `sendBeacon` 补写。
- 翻章保留滚动位置策略：新章从顶部开始，返回上一章恢复位置。
- 删除、清空、换源必须二次确认。
- 主题、字号、行距、版心存 `localStorage`，跨页面生效。

| 断点 | 布局 |
|---|---|
| ≥ 1280 | 侧栏 244 + 内容 1200，书架 6 列 |
| 1080–1279 | 侧栏 76（图标）+ 内容自适应，书架 4–5 列 |
| 720–1079 | 侧栏 76，详情页封面 160，目录单列 |

触控目标 ≥ 44×44；底部安全区 `env(safe-area-inset-bottom)`。

## 11. 无障碍

- 正文对比度：纸 12.8:1、夜 11.4:1；次要文字 ≥ 4.6:1。
- 焦点环：`outline: 2px solid var(--accent); outline-offset: 2px`，不因 `:focus{outline:none}` 丢失。
- 图标按钮必须有 `aria-label`；当前导航 `aria-current="page"`。
- 抽屉/弹窗：焦点捕获、`Esc` 关闭、关闭后焦点回到触发按钮。
- 状态不只靠颜色：文字 + 圆点/形状。
- 动效遵循 `prefers-reduced-motion`。
- 语义结构：`header/nav/main/aside/footer`，标题层级不跳级。

第一版「纸上书房」偏文艺纸感，用户反馈希望更二次元、并有角色让风格立起来。这一阶段不改信息架构

## 9. 分层与回滚

```
style.css（旧基础层，老页面在用）
```

要回退到纸上书房，只需在 `base.html` 里去掉 `otaku.css` 那一行；`ui.css` 里的变量与组件不受影响。

# 第三阶段：品牌 · 书萤 / FIREFLY LIBRARY

原来叫「轻库」，太泛（轻小说 + 库），既没有画面也没有记忆点。改名时定了三条标准：
两个字（能塞进 42px 的方块标）、一眼能想出画面（好做 logo）、和「夜读 / 星屑 / 书房」的既有设定不打架。

## 16. 名字

**书萤 / FIREFLY LIBRARY**，取「书页如翼，一点萤光」。

- 画面：夜里翻开的书页像一对翅膀，上面停着一点萤火——正好对应书架的夜间主题和星屑装饰。
- 和现有设定的关系：**书萤** 是这个书房的名字，**星屑书房** 是书房里的那间屋子，六位角色住在屋里。
  所以皮肤名不用改，品牌名换了。
- 备用方案（没选）：`星屑文库`（和皮肤名撞车，四个字进不了方块标）、`灯下`（偏文艺，不好做图形）。

代码里仍然叫 `novelhub`（包名 / 命令 / 数据库路径都没动），只有**对外显示名**换了：
页面标题、侧栏品牌、面包屑、页脚、封面占位标签、人设 prompt 里的自称。

## 17. 图形标

三层结构：**书页（左右两片，中缝留 1px 当书脊）+ 萤光（圆点 + 外晕）+ 星屑（两颗四角星）**。
纯白单色，叠在渐变方块上；不用渐变描边，缩到 16px 也不糊。

| 文件 | 用途 |
| --- | --- |
| `static/brand/mark.svg` | 纯白标记，叠在 `.brand-mark` / `.brand-mini` 的渐变方块里 |
| `static/brand/favicon.svg` | 应用图标（64×64，自带渐变底 + 高光），`<link rel="icon">` 用它 |
| `static/brand/lockup.svg` | 横版组合（标 + 书萤 + FIREFLY LIBRARY），给 README / 文档用 |

预览页：`design/brand-preview.html`（各尺寸 16/24/32/48/72/96 与深浅底对照）。

尺寸规则：方块 42px 时标 27px（64%），移动端 32px 方块里标 21px（66%）。
方块保持 `rotate(-6deg)` 的贴纸感，原来给「轻」字做点缀的那颗白点已经去掉，因为图形标自己带萤光。

## 18. 顺手修的两处

- **静态资源版本号**：以前是 `int(time.time())`，每次重启都变，浏览器缓存永远失效；
  现在按 `static/` 下文件的 mtime+size 算 md5 前 8 位（图片除外），配合
  `SEND_FILE_MAX_AGE_DEFAULT = 7 天`——改文件才换 URL，没改就真缓存。首页渲染仍 ~17ms。
- **聊天页角色联动**：`/chat?who=miku` 时侧栏「今日担当」还是栞。现在 `base.html` 用
  `persona.id` 决定 `data-cast`，`cast.js` 也改成 `PAGE_CAST[page] || data-cast || 'shiori'`，
  后端说了算、前端只兜底。
- **聊天可以中途停**：生成中发送键变成方块「停止」，点一下中断，半截回复保留不丢。
